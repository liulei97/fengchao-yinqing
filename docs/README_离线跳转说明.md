# 蜂巢引擎｜Personal Harness V8 + 桌面概念原型 v0.4

## 使用方式（无网络）

1. 将 ZIP 解压到同一个文件夹，保持文件原来的相对位置。
2. 双击 `index.html`（与 `蜂巢引擎_PersonalHarness_V8_新增桌面原型入口.html` 内容相同）进入 V8 产品展示。
3. 通过页面顶部的 **「桌面原型 ↗」**、首页的 **「体验桌面原型」** 或 **「一体化工作台」** 展区的入口卡片打开 `HiveEngine_Desktop_Concept_v0.4.html`。
4. 在桌面原型中体验 AI 对话、WebGIS 2D/3D、Geo、Visual、Delivery 等功能；使用浏览器的返回按钮回到 V8。

### 说明

- V8 根据你本轮上传的 `PersonalHarness_V8_RichComponents_Source(1).zip` 修改。
- v0.4 是此前的 `蜂巢引擎_PersonalHarness_桌面工作台_v0.4_统一品牌与Office成果制作.html` 原样复制，未重构。
- 所有入口使用相对路径，解压后可以本地离线跳转。
- 单独下载 V8 HTML 时，如需入口工作，必须将 `HiveEngine_Desktop_Concept_v0.4.html` 放到同目录。
- 两个页面都是概念交互展示，不代表已经接通真实模型、WebGIS、ArcGIS、Office 文档生成或任务调度服务。
- 本次仅修改 V8 页面入口、前端文案与附带资源，没有改变你正式 Personal Harness 的源码与部署状态。
