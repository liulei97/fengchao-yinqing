模型的职责是思考和理解

LLM 用于规划、检索策略、文本和分析；VLM 用于图面理解；Image Model 用于候选图生成。模型身份、版本、上下文和调用参数由 Model Router / Provider Adapter 记录。

工具的职责是真实执行

Knowledge MCP、Geo 开源 GIS Worker / ArcGIS Pro Bridge、CAD / Rhino / GH、ComfyUI 与外部 API 是独立能力。视觉模型生成的内容不冒充空间事实或工程数值。

审查和业务接受不是一回事

Reviewer 可独立核对冻结证据；Task Core 决定业务接受。多模型多数意见不能代替政策原文、GIS 回执、原生文件回读或必要人工审定。
