# 蜂巢引擎 · Personal Harness 全景产品展示

**在线预览：<https://liulei97.github.io/fengchao-yinqing/>**

一个统一的 Personal Harness，面向咨询、规划、政策研究、城市设计与项目交付：以任务为组织单元，共享资料、证据、专业软件、模型、审查与可编辑成果。本仓库是其**全景产品展示页**——页面呈现体系全部建成后的使用形态，交互演示采用示例数据。

## 仓库结构

| 文件 | 说明 |
|---|---|
| `index.html` | 展示页本体（原文件名：`蜂巢引擎_PersonalHarness_全景产品展示_完整版.html`，发布时改名为 `index.html` 以便 GitHub Pages 直达） |
| `docs/产品能力全景与内容映射.md` | 展示页的信息架构：展示模块 ↔ 产品能力 ↔ 技术体系对照，及关键产品边界（非开发实施计划） |
| `docs/样式说明.css` | 展示页样式说明文档 |

## 页面特点

- **单文件自包含**：全部样式与脚本内联，图片为 data URI，无任何外部网络请求（页面自带 CSP：`connect-src 'none'`）。
- **纯静态零依赖**：无需构建，任意静态服务器（含 GitHub Pages）可直接托管；`file://` 双击打开亦可。
- **内容覆盖**：一体化工作台、七领域全景、政策研究工作台、城市设计专题与全链路、平台运行架构、专业案例工作流、场景/工作链/成果展示。
