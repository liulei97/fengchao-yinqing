# 蜂巢引擎 · 产品能力与原型设计迭代图谱

日期：2026-10-22。

## 使用

- 双击 `index.html` 即可离线打开迭代图谱。历史预览加载 `archive/` 下的**真实原始 HTML 页面**，没有截图或重新绘制的“原型”。
- 左侧切换产品展示 / 桌面原型；中间直接操作旧页面；右侧查看本次能力与架构意义。
- 在「两个原版本，同屏对照」中选择两份历史 HTML 并排查看。
- 部分历史 HTML 本身属于模拟，依赖本地 HTTP 服务的应用功能不会因为复制 HTML 自动成为在线服务。
- 浏览器若出于安全策略限制 `file://` iframe 内部资源，请使用独立打开按钮，或在**本文件夹内**运行 `python -m http.server 8765 --bind 127.0.0.1`，再打开 `http://127.0.0.1:8765/`。
