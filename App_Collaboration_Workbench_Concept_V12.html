ARCHITECTURAL BOUNDARY

三层责任不能混为一谈

App Host 负责应用窗口、服务地址与视图生命周期；App Bridge 负责能力声明、输入输出、来源校验和回执；Task Core 管理任务授权、租约/栅栏、取消对账、质量门禁与业务接受。

UI 隔离最小权限有类型的命令可验证回执不可伪造验收
IMPLEMENTATION STRATEGY

L0 → L1 → L2 → L3：按价值渐进集成

L0 不需更改原 WebUI；L1 可用文件导入导出；L2 才要求 App Bridge 适配器；L3 需要与 Task Core 的尝试身份、恢复与质量门禁严格协同。任何等级下，宿主都不能越权直接修改正式 INDEX。
